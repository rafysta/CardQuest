# CardQuest カードイラスト制作依頼書（ChatGPT用）

この文書と添付の `イラスト依頼_カード一覧.csv` を ChatGPT に渡して、カードイラストを生成してもらうための依頼書です。
**この文書を丸ごと最初のメッセージに貼り付け（またはアップロード）てください。**

---

## 依頼内容

あなた（ChatGPT）には、タブレット向けカードゲーム「CardQuest」のカードイラスト **169枚** を、
添付CSVの一覧に沿って**少しずつバッチで**生成してもらいます。
CardQuest は2003年のフリーゲーム SOUL GATE のカードバトルを再構築したもので、
世界観は「魂・憑依・死者の書」を軸にしたダークファンタジーです。

## 出力仕様（全カード共通・厳守）

| 項目 | 指定 |
|---|---|
| 形式 | PNG（背景は透過にせず、画面いっぱいまで描き込む） |
| サイズ | 正方形 1024×1024（最低 256×256） |
| ファイル名 | CSVの「ファイル名」列のとおり。**カードID.png**（例：ワーウルフ→ `7.png`） |
| 文字 | **画像内に文字・数字・ロゴ・署名を一切入れない**（カード名や数値はゲーム側が描画します） |
| 枠 | **カード枠・額縁・飾り枠を描かない**。イラストのみを端まで描く |
| 構図 | **主題を画面中央に置く**。ゲーム内で上下を切られて横長（およそ中央の帯 40％）で表示される場面があるため、**重要な要素は上下中央の帯に収める**。頭や武器の先が上端・下端ぎりぎりにならないように |
| 視認性 | 82×82px まで縮小されても分かるよう、**主題のシルエットを大きく明快に**。背景は暗く主題は明るく、コントラストで浮かび上がらせる |

## 画風（169枚すべてで統一・毎バッチ冒頭に再掲すること）

**ダークファンタジーのトレーディングカードゲーム風・重厚な油彩タッチ。**

> dark fantasy trading card game illustration, dramatic oil painting style,
> rich painterly textures, moody chiaroscuro lighting, deep shadows,
> muted dark background with a vivid accent glow on the subject,
> centered composition, bold readable silhouette,
> no text, no letters, no border, no frame, no watermark

さらにカードの種類ごとに、差し色と題材の方向を変えます（ゲームUIの種類色と対応させるため）。

| 種類 | 題材 | 差し色（アクセント光） |
|---|---|---|
| モンスター（ID 1〜73） | クリーチャーの肖像・全身。生きて動いている瞬間 | **赤〜琥珀**の光 |
| 魔法（ID 101〜148） | 呪文の現象そのもの。発動の一瞬を切り取る | **青〜紫**の魔力光 |
| 技能（ID 151〜199） | 構え・紋章・状態など象徴的な場面 | **緑〜翡翠**の光 |

トーンの補足：残酷な流血表現は避けつつ、不気味さ・荘厳さは残す。
召還Lv 3以上のモンスター（CSVの「召還Lv」列）は上位カードなので、ひときわ神々しく・禍々しく、
画面を大きく使って描く。

## CSVの読み方

| 列 | 意味 |
|---|---|
| ID／ファイル名 | 出力ファイル名の元。**絶対に取り違えないこと** |
| 種類／カード名／効果テキスト | 題材の根拠 |
| 攻撃力・防御力・ＣＨ・召還Lv | 強さの雰囲気づけの参考（高いほど強大に） |
| 画像モチーフ案 | **描く内容の指定**。これを土台に、画風に合わせて細部を膨らませてよい。ただし別のモチーフに差し替えない |
| 状態 | 進捗管理用。完成したら発注側が「済」に書き換える |

## 進め方

1. **まずテストとして次の3枚だけ**を生成する：`7.png`（ワーウルフ）、`135.png`（雷撃）、`168.png`（石化）。
   3種類の差し色・画風の見本になる。発注側がOKを出すまで次へ進まない。
2. OK後、**1バッチ5枚ずつ**、CSVのID順に生成する。各バッチの冒頭で上の画風指定を必ず再掲
   （セッションが長くなると画風が流れて変わるのを防ぐため）。
3. 各画像は生成のたびに**ファイル名を明記**する。発注側はダウンロードして
   `CardQuest/assets/cards/` に置くだけで、ゲームに反映される。
4. 画風がずれてきたと感じたら、承認済みのテスト3枚を貼り直して「この画風に合わせて」と伝える。

## やってはいけないこと

- 画像内への文字・数字・枠・署名・透かし
- 写実的なグロテスク表現（骸骨・亡霊などは様式化された不気味さで表現する）
- 途中での画風変更（タッチ・彩度・線の太さを勝手に変えない）
- モチーフの取り違え（IDとファイル名の対応ミスは致命的。毎回CSVの行を確認する）
- 実在のゲーム・アニメ・カードゲームのキャラクターやカードデザインに似せること

## 対象外（生成しないもの）

- **ID 180『空白』**：無地のカードなので画像不要（ゲーム側で無地表示）
- **ID 91〜99（カース）**：憑依で生まれる呪いカード。第2期に、対応するモンスター
  （ID 65〜73）の完成イラストを元に「紫の霊気を纏った亡霊版」として依頼する予定。今回は作らない

## 発注側（本人）向けメモ

- 進捗はCSVの「状態」列で管理（未／済）。ChatGPT側には状態列の更新を任せない
- 受け取った画像は `assets/cards/<ID>.png` に置く → 置いた分から順にゲームに表示される（未設置は記号表示のまま）
- 詳細パネルは横長トリミング（380×150）なので、受け取ったら**上下が切れても成立するか**を確認。
  だめなら「主題を中央の帯に収めて」と再生成を依頼
- テスト3枚のOK基準：①82pxに縮めても何のカードか分かる ②3枚の画風が揃っている ③文字・枠が入っていない
