# カードの絵の置き場所

ファイル名は **カードID.webp** です。置くだけで、そのカードの絵として使われます。

| 種類 | IDの範囲 | 例 |
|---|---|---|
| モンスター | 1〜73 | ミルファイター＝`1.webp`、ヨルムンガンド＝`10.webp` |
| 魔法 | 101〜148 | 憑依解除＝`101.webp` |
| 技能 | 151〜199 | 停滞＝`151.webp` |
| おじゃま虫 | 200 | `200.webp`（M6 戦場ルール用のこのゲーム独自カード） |

## 新しい絵を足す・差し替えるときの手順（2026-09-02）

**発注した絵（1024×1024のPNG）はそのまま置かないこと。** 必ず変換してから置きます。

```
1) 描いた／発注した .png を assets/cards/ に置く（カードID.png）
2) python3 tools/shrink-assets.py     ← 640px の .webp を作る
3) 中身を確認して、元の .png を消す
```

- **640×640 の WebP** に揃えてあります。表示は**いちばん大きい情報パネルでも281px角**で、
  画面は1280×800固定・拡大しないので、これ以上の解像度は画面に出ません。
- 発注時のPNGのまま（1024×1024・1枚1.7MB）だと**169枚で295MB**になり、タブレットでは
  読み込みで固まります。WebP 640px なら**合計7.3MB**（2026-09-02に変換済み）。
  カード絵には透過部分が無いので、PNGで持つ意味はありません。
- 拡張子を変えたくなったら `js/layout.js` の **`ART_EXT`（1箇所）** を書き換えます。
- 推奨は **正方形**（表示側の枠も正方形なので端が切り落とされません）。
- 絵が無いカードは、カード名の略称の文字だけで表示されます。1枚ずつ足していけます。
- カードIDの一覧は `docs/イラスト依頼_カード一覧.csv` にあります。

## カース（91〜99）の絵は用意しなくてよい

憑依で生まれるカース（91〜99）には**専用の絵を置く必要がありません**。
カースは「通常攻撃で倒されたユニットの霊が取り憑いたもの」で、
**カースID − 26 ＝ 取り憑いた元ユニットのID**（91→65 ヘルファイア 〜 99→73 アースバウンド）
という対応があります。

そのため画面側（`js/layout.js` の `artSrcId()`）が自動で元ユニットの絵を読み込み、
CSS（`css/style.css` の `img.curse-art`）で紫の心霊風に加工して表示します。
元ユニット 65〜73 の絵さえ置いてあれば、カース9種の絵も自動で揃います。
