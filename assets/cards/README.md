# カードの絵の置き場所

ファイル名は **カードID.png** です。置くだけで、そのカードの絵として使われます。

| 種類 | IDの範囲 | 例 |
|---|---|---|
| モンスター | 1〜73 | ミルファイター＝`1.png`、ヨルムンガンド＝`10.png` |
| 魔法 | 101〜148 | 憑依解除＝`101.png` |
| 技能 | 151〜199 | 停滞＝`151.png` |

- IDは「デッキ編集」画面の詳細パネルにも表示されます。
- 推奨サイズは正方形 256×256 以上。表示は 82×82（場）／380×150（詳細）です。
- 絵が無いカードは、種類の記号（⚔ ✦ ✚）だけで表示されます。1枚ずつ足していけます。
- `.webp` を使いたい場合は `js/layout.js` の `ART_DIR` のすぐ下、拡張子を変えてください。
